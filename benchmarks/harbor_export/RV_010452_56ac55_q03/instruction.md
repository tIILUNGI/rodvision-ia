# Visual Road Inspection Task

Analyze the provided road image (`input/image.png`) and answer the question below.

### Question
**Return the bounding box of the largest pothole in the image. Use normalized coordinates with the origin at the top-left corner.**


### Output Requirements
- Format: `bbox_normalized`
- Guidance: JSON list [x1, y1, x2, y2] with values in [0, 1], x1<x2 and y1<y2.
- Save your final concise answer into `output/answer.txt`.
